# Sourcing and Ordering

Follow this guide to:

- Give every part on your board a confirmed LCSC supplier part.
- Freeze procurement so the parts list is bound to one revision.
- Build a cost report you can trust.
- Clear the release blockers and order from JLCPCB, or hand off the package yourself.

Each step says what Synth does when something is missing, stale, or unavailable.

<Callout type="info" title="Nothing is ordered without you">

Synth never places an order on its own, and never shows an order as placed until JLCPCB confirms it. Payment, cancellation and any change at JLCPCB stay in your JLCPCB account.

</Callout>

## Find and Confirm Parts

Open **Sourcing** from the tool rail (or **Open Sourcing & procurement** in the command palette). The parts list has one row for every placed reference (`C1`, `R1`, `U1`, and so on). A new board starts with no confirmed supplier parts.

1. Select a reference.
2. Use **Find LCSC part** to search the catalog, or enter an LCSC number directly.
3. Compare the candidates. Each one shows its LCSC number, MPN, package, stock and price tiers.
4. Assign the part, then confirm it in **LCSC identity review**.

A part is assigned to one reference, not to every copy of it. `C1` and `C2` can use different capacitors.

<Callout type="warn" title="The package must match the footprint">

If the candidate's package does not match the reference's footprint (for example, an 0603 part on an 0805 footprint), Synth refuses it and the reference stays unconfirmed. The Sourcing panel does not show a message for the refusal yet, so if a part will not stay confirmed, check its package and pick a candidate that matches the footprint.

</Callout>

Other cases you may see:

| What you did                            | What happens                                                              |
| :-------------------------------------- | :------------------------------------------------------------------------ |
| Searched with an empty query            | No candidates. Synth does not call the catalog.                           |
| Entered an LCSC number that is malformed | Refused. Nothing is saved and the reference stays unconfirmed.            |
| Entered an LCSC number that does not exist | Refused. Nothing is saved and the reference stays unconfirmed.          |
| Picked a part with no stock or price data | The part is shown with its stock and price as unknown. Synth does not invent values. |

### Assembly Disposition

Each reference has a **Disposition**: supplier assembly, hand assembly, do not populate, or mechanical. It decides whether the part is in the JLCPCB assembly order.

A hand-assembled or mechanical part still needs a confirmed LCSC part before procurement can be frozen.

## When the Parts Catalog Has Problems

The catalog is an outside service. When it misbehaves, your saved work is not affected: the parts list still loads and confirmed parts keep their identity.

| What the catalog does                     | What you see in Sourcing                                           |
| :---------------------------------------- | :----------------------------------------------------------------- |
| Does not answer, or answers with an error | No candidates. The panel does not yet say the catalog is down.     |
| Takes too long                            | No candidates, after about 10 seconds.                             |
| Sends a reply Synth cannot read           | No candidates. Synth retries once before giving up.                |
| Has no matching part                      | No candidates.                                                     |

Because all four look the same today, an empty result for a part you know exists usually means the catalog is unavailable. Search again shortly; candidates come back on the next search once it recovers.

## Freeze Procurement

When every reference has a confirmed part, open **Cost** from the tool rail and select **Freeze procurement**. Freezing records exactly which supplier part each reference uses, bound to the current revision.

- If any part is still unconfirmed, the freeze is refused: a **Could not freeze procurement** message names the part that is not reviewed.
- Freezing again without changes returns the same frozen record. Several people freezing at the same time also get one record.
- After the freeze, live price refreshes are labelled as live, so you can tell them apart from the frozen record.

<Callout type="warn" title="Some changes undo the freeze">

Changing a part's disposition, or saving a new revision of the design, invalidates the frozen procurement and the cost report. The panel says **The recorded lock belongs to an earlier revision. Freeze again to bind procurement to this one.** Select **Re-freeze procurement**, then rebuild the cost report.

</Callout>

## Build the Cost Report

Choose a **Build scenario** (how many boards are fabricated and assembled), then select **Calculate build cost**.

The report shows a **Complete total** only when every manufacturing and delivery cost is known. Otherwise it shows a **Known subtotal** and marks the report **Incomplete**, so a missing price never looks like a zero.

Some board profiles need a supplier quote. Enter the **Supplier quote ID**, amount, **Quote date** and **Quote valid until**.

| Situation                                  | What happens                                                       |
| :----------------------------------------- | :----------------------------------------------------------------- |
| The amount is zero or negative             | Refused with **Could not calculate the cost**: the quote needs a positive amount, a quote date and a validity date. |
| A date cannot be read                      | Refused the same way.                                              |
| The quote has expired                      | Kept on the report, but the report is not complete. You see **Some supplier offers expired**. |
| You set a **Target budget**                | The report says **Within budget**, **Over budget**, or **Budget indeterminate** when the total is not complete. |

## Clear the Release Blockers

Open **Delivery** from the tool rail. The **Delivery & manufacturing** view shows **Release readiness**: the ERC, DRC, manufacturing, procurement and cost state of this revision, and a **Blocking release** list.

| Blocker                     | What to do                                                       |
| :-------------------------- | :--------------------------------------------------------------- |
| Procurement not frozen      | Confirm every part in **Sourcing**, then freeze procurement in **Cost**. |
| Cost report incomplete      | Fill the missing costs in **Cost** and recalculate.              |
| Cost report stale           | Recalculate the cost report after the latest change.             |
| Erc not clean / Drc not clean | Fix the findings in **Checks** and rebuild.                    |
| Drc rule not attested / Drc attestation error | Build the board so the physical checks run against its declared rules. |
| Manufacturing not attested / Manufacturing files incomplete | Build the board to produce the full set of manufacturing files. |
| Stale checks                | Rerun the checks for the current source.                         |
| Revision not current        | Open the current revision; a release is bound to it.             |
| Release not approved        | Request approval in **Release readiness**.                       |

A release cannot be approved while any blocker is listed. An unknown check counts as a blocker; it is never shown as a pass.

## Order from JLCPCB

Ordering through Synth needs:

- JLCPCB Open Platform keys, added in **Settings** by a workspace admin or owner. Viewers and editors cannot add them.
- A deployment whose outgoing address is on your JLCPCB account's whitelist.
- A release with no blockers.

Without keys, the panel says **This workspace has no JLCPCB credentials**. You can still download the manufacturing package and upload it to JLCPCB yourself.

1. Select **Request quote**. Synth sends JLCPCB the frozen procurement, the build scenario quantity and the board profile.
2. Check the **JLCPCB quote** against your cost report.
3. Select **Place order**. Synth sends one order for the quote you confirmed.

What Synth guarantees:

- **No duplicate orders.** Retrying or double-clicking sends one quote request and one order.
- **No order without a quote.** An expired quote says **This quote has expired. Request a new quote to order.**
- **Only confirmed orders count.** If JLCPCB declines, the order shows **Rejected by JLCPCB**. If JLCPCB's reply cannot be matched to the quote, the order shows **Needs checking** and nothing more is ordered for that quote until someone checks it in the JLCPCB console.

<Callout type="warn" title="An order with no recorded outcome">

If Synth sent an order but never recorded JLCPCB's answer, the order shows **This order was sent to JLCPCB but its result was never recorded.** Synth will not send it again. Check your JLCPCB account, then an owner or editor uses **Record outcome** to note what happened.

</Callout>

Synth has no cancel button. Cancel an order in your JLCPCB account, then record the outcome in Synth.
