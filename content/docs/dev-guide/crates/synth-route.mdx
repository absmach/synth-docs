# `synth-route` Crate

`synth-route` is Synth's native deterministic router: a grid-based maze/A\* engine that turns a placement and a netlist into `synth_pcb` copper.

It is not the external-router adapter. `synth-router` selects and runs engines such as KiCadRoutingTools and FreeRouting; `synth-route` is the in-process router used for power rails and local routing.

## Modules

- `grid`, `miter` — routing grid and geometry repair.
- `bus`, `diff_pair`, `serpentine` — bus, differential-pair, and length-matching routing.
- `drc` — route-local checks.
- `logger` — `RoutingOutcomeRecord` for replay advice.
- `advisor` — a cost-advisor seam used by the enterprise EBM crate.

## Output

`synth_pcb::{Routing, Segment, Via, UnroutedNet}`. The same `(Board, Placement)` produces the same copper; the router never uses wall-clock or host state to break a tie.
