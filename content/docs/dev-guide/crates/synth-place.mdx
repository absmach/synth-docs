# `synth-place` Crate

`synth-place` solves physical component positions and rotations with integer-nanometer arithmetic. The same board and the same `placement_hint` constraints produce the same coordinates.

## Responsibilities

- Global placement and legalization.
- Floorplanning and outline packing.
- Constraint handling for `near`, `region`, `side`, `edge`, `rotation`, and `priority`.
- Placement fitness and routability estimates.
- Compaction in gap mode.

## Key modules

| Module                        | Responsibility                                           |
| :---------------------------- | :------------------------------------------------------- |
| `floorplan`, `outline_packer` | Board outline and coarse placement.                      |
| `fitness`                     | `PlacementFitness`, `FitnessMetric`, `fitness()`.        |
| `routability`                 | `RoutabilityEstimate`, `routability()`.                  |
| `cem`, `compact_gaps`         | Convex/electrostatic placement moves and compaction.     |
| `advisor`                     | Placement-advisor seam used by the enterprise EBM crate. |
| `board_family`                | Fixed-form-factor profiles.                              |
| `score`, `modules`            | Deterministic scoring and module grouping.               |

The placer does not route. It produces the placement that `synth-route`/`synth-router` and `synth-drc` consume.
