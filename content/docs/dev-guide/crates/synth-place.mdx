# `synth-place` Crate

The `synth-place` crate calculates optimal (X, Y) coordinates and rotations for components to minimize trace lengths and prevent thermal/mechanical overlapping.

## Modules

- `placement`: Simulated annealing and force-directed component placement.
- `spatial`: BVH (Bounding Volume Hierarchy) spatial indexing provided by `synth-geometry`.
