# `synth-smt` Crate

`synth-smt` is a small, pure-Rust solver for the single-variable linear constraints Synth's ERC rules emit. It evaluates a constraint in sub-microsecond time and avoids an external C/C++ dependency such as Z3.

## Scope

- One variable per assertion (a width, a clearance, a current, a temperature rise).
- Linear inequalities and equalities.
- A `solve_smt` patch kind lets an agent ask for the range that satisfies the design's constraints.

The crate is intentionally not a general SMT solver. If a rule needs multi-variable reasoning, it belongs in `synth-validate` as a dedicated rule, not as a larger solver dependency.
